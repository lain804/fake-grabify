# fake-grabify

Tool for overwhelming phishing attempts with synthetic data

## Install

Choose either method to make `fake-grabify` available as executable from your shell.

### [pip](https://pip.pypa.io/en/stable/cli/pip_install/)

```sh
python -m pip install --user git+https://github.com/lain804/fake-grabify.git
```

### [uv](https://docs.astral.sh/uv/concepts/tools/)

```sh
uv tool install git+https://github.com/lain804/fake-grabify.git
uv tool update-shell
```

## Usage

```sh
fake-grabify [-hurc] [url]
```
